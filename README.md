# Well-being Matters

Landing page for **Well-being Matters** — a public health nutrition organization founded by Dr. Mary Oyewole-Asowata. Focused on nutrition accountability, food literacy, and community-driven healthy living.

## Tech Stack

- **Next.js 15** (App Router, static export)
- **Tailwind CSS v4**
- **@paper-design/shaders-react** — DotOrbit WebGL shader on hero
- TypeScript

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```
